# COMP250EssayRevision

# project overview
The repository contains the revision of an essay that argues about Germany's responsibility for the outbreak of World War 1. It shows how tools such as Git, Githuv, Pandoc, and Zotero came into play during the revision process.

# contents
WWIrevision.md - the fully revised version of the essay in markdown format

WWIessaybib.json - the citation information imported by Zotero which was used by pandoc to generate the citations

.gitignore - the file to ignore docx files when being tracked by git. Used to 'ignore' the test.docx file

README.md - Overview of the revision

# original essay 
The original essay was written as an assignment in a history class, with World War 1. It analyzed a stance that Germany was responsible for the outbreak of World War 1, and the stance I took on the essay was that Germany was indeed responsible for the outbreak.

# revision process 
VS Code (Visual Studio Code) was used to edit the essay in markdown format, which was converted from docx using pandoc. The esssay was reorganized for each sentence to have its own line. Each line was read thoroughly, and revised/changed as needed with additional sentences/statements being added before or after to improve the overall flow of the essay. Git and github was used in order to save any revisions, and save previous versions.
